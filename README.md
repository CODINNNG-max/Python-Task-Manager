# Python-Task-Manager
A locally run, command-line Python task manager that allows users to add, view and remove tasks. Tasks are stored in a local JSON file, allowing them to persist between program executions.

Features

- Add new tasks
- View saved tasks
- Remove tasks by their number
- Automatically save changes to a JSON file
- Handle missing or corrupted JSON files
- Validate user input

Concepts Demonstrated

- File handling
- JSON data storage
- Functions and parameters
- Lists and dictionaries
- Exception handling
- Input validation

Technology: Python 3
